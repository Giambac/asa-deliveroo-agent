# LLM Deliveroo Agent

This agent keeps the working BDI/planning code from `../agent`, but replaces the option selector with an LLM deliberation module.

The LLM does not control raw movement directly. It chooses among safe candidate intentions generated by the BDI layer:

- `go_pick_up`
- `go_deliver`
- `go_explore`

The plan library still executes the selected intention with pathfinding, fallback movement, opportunistic pickup, and delivery.

## Run

From `ASA-project1`:

```bash
npm run agent:llm -- -host=http://localhost:8080 -name=test-llm
```

or:

```bash
node agent-llm/index.js -host=http://localhost:8080 -name=test-llm
```

## LLM Configuration

For the UniTN LiteLLM proxy:

```bash
set LITELLM_BASE_URL=https://llm.bears.disi.unitn.it/v1
set LITELLM_API_KEY=your-key
set LOCAL_MODEL=llama-3.3-70b-lmstudio
```

For another OpenAI-compatible endpoint:

```bash
set OPENAI_BASE_URL=https://api.openai.com/v1
set OPENAI_API_KEY=your-key
set OPENAI_MODEL=gpt-4.1-mini
```

If no API key is set, the agent still runs and falls back to the heuristic option selector.

## What Makes It an LLM Agent

`llmDecision.js` sends a compact world state and candidate options to the model. The model returns JSON:

```json
{"index":0,"reason":"deliver carried parcels before reward decays"}
```

`llmIntentionRevision.js` then starts the selected intention through the same plan library used by the normal BDI agent.
